# `@yydb/iris-adapter-redis`

Foreign-store adapter for Redis (keyspace / cache role). Commands stay **private** inside this package.

| Prefer                                                          | Avoid                        |
|-----------------------------------------------------------------|------------------------------|
| [`redis`](https://www.npmjs.com/package/redis) (node-redis, JS) | Native Redis client bindings |

```bash
pnpm add @yydb/iris @yydb/iris-adapter-redis redis
```
